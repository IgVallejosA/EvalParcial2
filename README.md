Sistema backend para gestión de torneos, equipos, jugadores, partidos y estadísticas del mundo eSports.  
Arquitectura de microservicios independientes, cada uno con su propia base de datos.

## Integrantes.
  
- Ignacio Vallejos
- Camilo Covarrubias

## Funcionalidades principales
- CRUD completo de equipos, jugadores, torneos, partidas, rankings, estadísticas, juegos, patrocinadores, streamers y transferencias.
- Validaciones de datos con Bean Validation.
- Manejo global de excepciones y logs estructurados.
- Comunicación entre microservicios vía WebClient.
- Persistencia con JPA/Hibernate y migraciones Flyway.
